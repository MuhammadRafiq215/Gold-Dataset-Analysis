# Gold Dataset Analysis

## 📊 Project Overview

This project focuses on analyzing gold price data using Python and data science techniques.

The analysis explores the dataset through data cleaning, exploratory data analysis, visualization, statistical analysis, and regression-based modeling to understand patterns and relationships in gold prices.

## 🎯 Objectives

- Load and inspect gold price data
- Clean and prepare the datasets
- Perform exploratory data analysis (EDA)
- Identify important patterns and relationships
- Create meaningful data visualizations
- Apply regression and machine learning techniques
- Evaluate model performance
- Extract useful insights from the data

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📁 Project Files

| File | Description |
|---|---|
| `Gold_Dataset_Assigenment.ipynb` | Main Jupyter Notebook containing the analysis |
| `Gold Price Prediction.csv` | Gold price dataset used for analysis |
| `Pakistan_Gold_Daily_Regression_2025_to_2026-09-01 (1).xlsx` | Additional gold price data |

## 📈 Analysis

The notebook contains:

- Data inspection
- Data preprocessing
- Exploratory Data Analysis
- Visualization
- Correlation analysis
- Regression modeling
- Model evaluation
- Data-driven observations
